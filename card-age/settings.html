debug - Set this to 1 if you are facing an issue with the Power-Up. Then go to the browser's Developer Console to check out the log.
unit - If you want to change the unit of measure for the duration in list. Possible values are days, minutes and hours.
refresh - Set this to the amount of seconds you want the card badges to be updated. I.e. 5 means the durations in cards are refreshed each 5 seconds
decimalplaces - Set this to the number of decimal places to show in the duration for each card. I.e. 0 means no decimal places will be shown
badgecolor - Set this to the background color you want for the time badge. Set it to none if you want a transparent background
Refresh the board after you have clicked save for the settings to kick-in.
