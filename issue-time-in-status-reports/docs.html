Issue Time in Status Reports

Easily find the time spent in the current status for the issue being viewed

Features

  • Custome fields are indexed and you can create your own reports and dashboards utilizing the durations on each statuses
  • Get the time spent on other statuses as well as a custom field, not just the current issue status

Few more details

The app measures the time each issue has been on a specific Status. The app measures even the previous duration the issue has been on a specific status. For instance, if initially the issue has been for 1 minute in TODO, then you move it to DOING, then you move it again to TODO. After a minute, it will report as 2 minutes spent in TODO status.
After the installations the add-on can be accessed from the configuration page. You will see a link to jump to configuration right after installation.
The calculated time is measured in days.
